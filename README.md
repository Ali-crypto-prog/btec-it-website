# My BTEC IT Website Project
This is a multi page website that I built from scratch for one of my BTEC National Diploma IT assignments. I wanted to make something that was clean, easy to look at, and fully working on as many devices as possible given the restricted time I had been given.

## What it does and how I built it
- **Works on most screens:** I used CSS styling and media queries so that the layout automatically shrinks or grows (adapts) whether you are looking at it on a phone, tablet, or laptop/desktop.
- **Interactive features:** I used JavaScript to add basic user interactions, like form checks and working buttons.
- **Clean layouts:** It was built using standard and organized HTML structure.

## Programming languages used
- HTML
- CSS
- JavaScript
